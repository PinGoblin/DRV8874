    Pin backends¶

    Hardware pin backends.

    A backend creates three kinds of pin: digital outputs, PWM outputs and digital inputs. Pins are cached by GPIO number, so several boards in a daisy chain can share one nSLEEP line: ask for the same pin twice and you get the same object back. (nFAULT must not be shared: each board needs its own.) A shared pin is released when the last user closes it.

    Backend Use
    GpiozeroBackend Default on a Raspberry Pi (Pi 5 supported). Software PWM, or hardware PWM on GPIO12/13/18/19
    MockBackend Testing and dry runs without hardware

    HW_PWM_CHANNELS module-attribute ¶

    HW_PWM_CHANNELS = {12: 0, 13: 1, 18: 0, 19: 1}

    Raspberry Pi GPIOs with a hardware PWM channel, mapped to the channel number.

    GpiozeroBackend ¶

    GpiozeroBackend(hardware_pwm: bool = False, pwm_chip: int = 0, pin_factory=None)

    Bases: Backend

    Raspberry Pi backend using gpiozero (BCM pin numbers).

    gpiozero's software PWM is reliable only up to about 1 kHz, which makes motors whine. For silent 20 kHz PWM, set hardware_pwm=True and use GPIO12, 13, 18 or 19 for the EN pins. This needs the rpi-hardware-pwm package and dtoverlay=pwm-2chan in /boot/firmware/config.txt. The Pi has two hardware PWM channels, so it covers one board.

    Parameters:

    Name Type Description Default
    hardware_pwm bool

    Use hardware PWM on GPIO12/13/18/19. Other EN pins fall back to software PWM.

    		 False
    pwm_chip int

    PWM chip number for rpi-hardware-pwm: 0 on a Pi 4, 2 on some Pi 5 kernels.

    		 0
    pin_factory

    Optional gpiozero pin factory (for example a remote or mock factory).

    		 None

    Raises:

    Type Description
    ConfigError

    gpiozero is not installed.

    MockBackend ¶

    MockBackend()

    Bases: Backend

    Hardware-free backend for tests and dry runs.

    Example 
    from pingoblin_motor import MockBackend, MotorBoard

be = MockBackend()
board = MotorBoard(a_en=12, a_ph=5, fault_pin=19, backend=be)
board.motor_a.forward(50)
assert be.pins[12].duty == 0.5
be.pins[19].level = False        # simulate nFAULT going low
