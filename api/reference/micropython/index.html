    MicroPython reference¶

    The MicroPython module is imported as pingoblin_motor on the board. It is documented here as pingoblin_motor_mp so it doesn't clash with the Raspberry Pi package.

    pingoblin_motor for MicroPython: the PinGoblin Board A (2 × DRV8874) motor library in one file.

    Runs on ESP32 and Raspberry Pi Pico / Pico 2 with MicroPython 1.20 or later, and has the same class and method names as the Raspberry Pi library: MotorBoard, Motor, MotorChain, forward(), reverse(), run(), start(), stop() / brake(), coast(), speed_pc and current.

    There are no threads. Timed runs, ramps and fault checks happen in update(), which must be called in one of three ways:

    • as an asyncio task: asyncio.create_task(board.run_monitor());
    • through the blocking helpers: board.pause(2) or motor.forward(50, 2, wait=True);
    • from your own main loop, every 10–50 ms.

    The source is about 63 KB, much of it docstrings. Precompile it with mpy-cross and copy the .mpy to the board: .mpy files leave the docstrings out and skip on-board compilation, which can run out of RAM on an ESP32 without PSRAM.

    Example 
    from pingoblin_motor import MotorBoard

board = MotorBoard(a_en=25, a_ph=26, b_en=27, b_ph=33, sleep_pin=32, fault_pin=39)
board.enable_monitor(on_fault=print)
board.motor_a.forward(60, duration=2, wait=True)

    ISENSE_V_PER_A module-attribute ¶

    ISENSE_V_PER_A = 0.675

    Board A ISENSE gain: 0.675 V per amp (1.5 kΩ × 450 µA/A).

    WAKE_MS module-attribute ¶

    WAKE_MS = 2

    Milliseconds to wait after waking the drivers (the DRV8874 needs about 1 ms).

    DEFAULT_ACTIONS module-attribute ¶

    DEFAULT_ACTIONS = {FaultType.STALL: FaultAction.BRAKE, FaultType.CURRENT_LIMIT: FaultAction.NONE, FaultType.DRIVER_FAULT: FaultAction.SLEEP, FaultType.OPEN_LOAD: FaultAction.BRAKE, FaultType.OVERLOAD: FaultAction.BRAKE, FaultType.BOARD_OVERLOAD: FaultAction.BRAKE, FaultType.CHAIN_OVERLOAD: FaultAction.BRAKE, FaultType.SENSOR_ERROR: FaultAction.NONE}

    Default FaultAction for each FaultType.

    LATCHING module-attribute ¶

    LATCHING = (FaultType.STALL, FaultType.DRIVER_FAULT, FaultType.OPEN_LOAD, FaultType.OVERLOAD)

    Fault types that latch until clear_fault().

    DRIVER_FAULT_DEBOUNCE_MS module-attribute ¶

    DRIVER_FAULT_DEBOUNCE_MS = 200

    Milliseconds nFAULT must stay low, with no motor driven, before DRIVER_FAULT.

    OVERLOAD_DEBOUNCE_MS module-attribute ¶

    OVERLOAD_DEBOUNCE_MS = 1000

    Milliseconds over the limit before BOARD_OVERLOAD / CHAIN_OVERLOAD.

    CURRENT_LIMIT_REPEAT_MS module-attribute ¶

    CURRENT_LIMIT_REPEAT_MS = 5000

    Minimum milliseconds between repeated CURRENT_LIMIT warnings.

    OPEN_LOAD_MIN_DUTY module-attribute ¶

    OPEN_LOAD_MIN_DUTY = 0.2

    Open-load checks run only at or above this duty (0–1).

    What a motor is doing (string constants).

    "coasting": outputs open; spins down freely.

    ControlMode ¶

    Control mode set by the PMODE jumper JP1 (string constants).

    Attributes:

    Name Type Description

    PWM

    FaultType ¶

    Every fault the library can detect (string constants).

    Constant Detected when Needs sensor
    STALL Current at or above stall_current for stall_time while driven, or nFAULT low for stall_time without a sensor No
    CURRENT_LIMIT nFAULT low while driven (warning, at most every 5 s) No
    DRIVER_FAULT nFAULT low for 0.2 s with no motor driven: short, overcurrent or over-temperature No
    OPEN_LOAD Under open_load_current for open_load_time while driven at 20 % or more Yes
    OVERLOAD Above continuous_current for overload_time Yes
    BOARD_OVERLOAD Board supply current above fuse_rating (3 A) for 1 s Yes
    CHAIN_OVERLOAD Chain supply current above the chain limit (6 A) for 1 s Yes
    SENSOR_ERROR The current sensor could not be read Yes

    FaultAction ¶

    What to do to a motor when a fault is detected (string constants).

    Attributes:

    Name Type Description
    NONE

    Record and report only.
    BRAKE

    Brake the motor.
    COAST

    Coast if possible, otherwise brake.
    SLEEP

    Sleep the board (all motors coast). Brakes if there is no sleep pin.

    ADS1115 ¶

    ADS1115(i2c, address=72, full_scale=4.096, data_rate=860)

    PinGoblin ADS1115 board (or any ADS1115) on a machine.I2C bus.

    Each conversion averages over about 1.2 ms (860 samples/s), so with PWM a reading is roughly duty × motor current.

    		 72

    		 860

    ADCChannel ¶

    ADCChannel(pin, vref=3.3)

    The microcontroller's own ADC on an ISENSE pin (ESP32: ADC1 pins 32–39; Pico: GP26-28).

    The built-in ADC samples instantly, so with PWM each sample is either the full motor current or zero. Boards average 16 samples per reading by default for this sensor. On the ESP32 the input range is set to about 0–3.1 V (11 dB attenuation).

    Parameters:

    Name Type Description Default
    pin

    ADC-capable GPIO.

    		 required
    vref

    ADC reference (V), used only where read_uv() isn't available (Pico).

    		 3.3

    Motor ¶

    Motor(name, board, en_pin, ph_pin, mode, pins, sensor=None, invert=False, pwm_freq=20000, min_speed_pc=0, ramp_time=0.0, reverse_delay=0.1, stall_current=None, stall_time=0.5, start_grace=0.3, open_load_current=0.03, open_load_time=1.0, continuous_current=1.5, overload_time=5.0, policy=None)

    		 None

    MotorBoard ¶

    MotorBoard(name='board', a_en=None, a_ph=None, b_en=None, b_ph=None, sleep_pin=None, fault_pin=None, mode='ph_en', logic_voltage=3.3, adc=None, a_sense_channel=None, b_sense_channel=None, a_sensor=None, b_sensor=None, sense_samples=None, pins=None, pwm_freq=20000, motor_names=('a', 'b'), motor_options=None, a_options=None, b_options=None, fuse_rating=3.0)

    One Board A dual DC motor driver. Pins are GPIO numbers.

    Several boards can share one sleep_pin (one e-stop line). Each board needs its own fault_pin: a fault_pin already used by another open board is rejected.

    Example 
    board = MotorBoard(a_en=25, a_ph=26, b_en=27, b_ph=33, sleep_pin=32, fault_pin=39,
                   a_sensor=ADCChannel(34), b_sensor=ADCChannel(35))
board.enable_monitor(on_fault=print)
board.motor_a.forward(60)
board.pause(2)
board.stop_all()

    Parameters:

    name

    		 'board'
    a_en

    		 None
    a_ph

    GPIO for A_PH (J3 pin 4).

    		 None
    b_en

    GPIO for B_EN (J3 pin 5), or None for a single motor.

    		 None
    b_ph

    GPIO for B_PH (J3 pin 6), or None.

    		 None
    sleep_pin

    GPIO for nSLEEP (J3 pin 9), or None. The board pulls nSLEEP high, so the drivers are awake without it. Several boards may share it.

    		 None

    		 None
