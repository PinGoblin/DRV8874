    MotorBoard¶

    MotorBoard: one Board A (two DRV8874 channels) and its shared lines.

    ISENSE_V_PER_A module-attribute ¶

    ISENSE_V_PER_A = 0.675

    Board A ISENSE gain: 0.675 V per amp.

    VREF_V module-attribute ¶

    VREF_V = 1.24 * (1 + 10.0 / 15.0)

    Board A current-limit reference: a TLV431 set to about 2.07 V, independent of VLOGIC.

    WAKE_TIME_S module-attribute ¶

    WAKE_TIME_S = 0.0015

    Seconds to wait after waking the drivers (the DRV8874 needs about 1 ms).

    MotorBoard ¶

    MotorBoard(name: str = 'board', *, a_en: int, a_ph: int, b_en: Optional[int] = None, b_ph: Optional[int] = None, sleep_pin: Optional[int] = None, fault_pin: Optional[int] = None, mode: str = 'ph_en', logic_voltage: float = 3.3, adc: Optional[object] = None, a_sense_channel: Optional[int] = None, b_sense_channel: Optional[int] = None, sense_samples: int = 4, a_sensor: Optional[CurrentSensor] = None, b_sensor: Optional[CurrentSensor] = None, backend: Optional[Backend] = None, pwm_frequency: float = 1000.0, motor_names=('a', 'b'), motor_options: Optional[dict] = None, a_options: Optional[dict] = None, b_options: Optional[dict] = None, fuse_rating: float = 3.0, supply_voltage: Optional[float] = None)

    One Board A dual DC motor driver.

    Pins are BCM GPIO numbers. Motor B is optional. Boards work as context managers and close on exit.

    Several boards can share one sleep_pin (one e-stop line). Each board needs its own fault_pin: a shared fault line overloads the nFAULT outputs and hides which board faulted, so a fault_pin already used by another open board is rejected.

    Example 
    from pingoblin_motor import MotorBoard

with MotorBoard(a_en=12, a_ph=5, b_en=13, b_ph=6,
                sleep_pin=26, fault_pin=19) as board:
    board.start_monitor(on_fault=print)
    board.motor_a.forward(60, duration=2, wait=True)

    Parameters:

    Name Type Description Default
    name str

    Board name, used in "board.motor" addresses. Must not contain ..

    		 'board'
    a_en int

    GPIO for A_EN (J3 pin 3).

    		 required
    a_ph int

    GPIO for A_PH (J3 pin 4).

    		 required
    b_en Optional[int]

    GPIO for B_EN (J3 pin 5), or None for a single motor.

    		 None
    b_ph Optional[int]

    GPIO for B_PH (J3 pin 6), or None.

    		 None
    sleep_pin Optional[int]

    GPIO for nSLEEP (J3 pin 9), or None. The board pulls nSLEEP high, so the drivers are awake without it. Needed to coast in PH/EN mode and for sleep(). Several boards may share it.

    		 None
    fault_pin Optional[int]

    GPIO for nFAULT (J3 pin 10), or None. Needed for stall detection without a current sensor. Must be a different GPIO for each board.

    		 None
    mode str

    "ph_en" (JP1 open, default) or "pwm" (JP1 bridged).

    		 'ph_en'
    logic_voltage float

    VLOGIC (V), 3.0–5.5. Checked for range only: the current limit is fixed at about 3 A whatever the logic voltage.

    		 3.3
    adc Optional[object]

    A pingoblin_ads1115.ADS1115 for current sensing, created with rate=860. See ADS1115Channel.

    		 None
    a_sense_channel Optional[int]

    ADS1115 input wired to A_ISENSE.

    		 None
    b_sense_channel Optional[int]

    ADS1115 input wired to B_ISENSE.

    		 None
    sense_samples int

    Readings averaged per current measurement.

    		 4
    a_sensor Optional[CurrentSensor]

    Any CurrentSensor for motor A, instead of an ADS1115 channel.

    		 None
    b_sensor Optional[CurrentSensor]

    The same for motor B.

    		 None
    backend Optional[Backend]

    Pin Backend. Default: GpiozeroBackend.

    		 None
    pwm_frequency float

    PWM frequency (Hz).

    		 1000.0
    motor_names

    Names for motors A and B, for example ("left", "right").

    		 ('a', 'b')
    motor_options Optional[dict]

    Keyword arguments for both Motors.

    		 None
    a_options Optional[dict]

    Keyword arguments for motor A only (override motor_options).

    		 None
    b_options Optional[dict]

    Keyword arguments for motor B only.

    		 None
    fuse_rating float

    The board's continuous current rating (A), for BOARD_OVERLOAD. The on-board 4 A fast-acting (high I2t) fuse allows 3 A continuously.

    		 3.0
    supply_voltage Optional[float]

    Motor supply voltage (V), 6–30, or None. Required when a motor is given motor_voltage: the library then limits that motor's PWM duty so the average voltage across it does not exceed its rating.

    		 None

    Raises:

    Type Description
    ConfigError

    Invalid mode, voltage, names or pins, or a fault_pin already used by another open board.

    current_limit property ¶

    current_limit: float

    Driver current limit per motor (A): about 3 A, fixed on the board.

    ITRIP = VREF / 0.675 V/A, with VREF ≈ 2.07 V from an on-board reference.

    motor_a property ¶

    motor_a: Motor

    The first Motor (J4).

    motor_b property ¶

    motor_b: Optional[Motor]

    The second Motor (J5), or None on a single-motor setup.

    is_asleep property ¶

    is_asleep: bool

    True while nSLEEP is driven low.

    fault_active property ¶

    fault_active: Optional[bool]

    True while nFAULT is low (a fault, or a driver current-limiting). None if fault_pin isn't wired.

    total_current property ¶

    total_current: Optional[float]

    Sum of the motors' last supply-side current readings (A).

    None unless every motor has a sensor and has been read at least once.

    sleep ¶

    sleep() -> None

    Pull nSLEEP low: every motor on this nSLEEP line coasts and the drivers draw almost no current.

    All motors on the line are stopped first, so they stay stopped when the board wakes.

    Raises:

    Type Description
    ConfigError

    No sleep_pin configured.

    wake ¶

    wake() -> None

    Drive nSLEEP high and wait for the drivers to wake (about 1.5 ms). Run commands wake the board automatically.

    stop_all ¶

    stop_all() -> None

    Brake every motor on this board.

    coast_all ¶

    coast_all() -> None

    Coast every motor on this board.

    In PH/EN mode this sleeps the board, so it needs sleep_pin. Without one the motors brake.

    start_monitor ¶

    start_monitor(interval: float = 0.05, on_fault=None)

    Start a background fault monitor for this board alone.

    When the board joins a MotorChain, the chain's monitor takes over.

    Parameters:

    Name Type Description Default
    interval float

    Seconds between checks.

    		 0.05
    on_fault

    Optional handler(fault) called for every fault.

    		 None

    Returns:

    Type Description

    The running FaultMonitor.

    stop_monitor ¶

    stop_monitor() -> None

    Stop the board's fault monitor, if running.

    close ¶

    close() -> None

    Stop the monitor, brake every motor and release every pin.
