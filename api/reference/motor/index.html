    Motor¶

    The Motor class: one brushed DC motor on one DRV8874 channel.

    Direction ¶

    Bases: Enum

    Direction of rotation.

    "Forward" follows the board's (and TI's) convention: PH high, OUT1 positive. Which way the shaft turns depends on the wiring; use invert=True to swap.

    Attributes:

    Name Type Description
    FORWARD

    PH high (OUT1 positive).
    REVERSE

    PH low (OUT2 positive).

    MotorState ¶

    Bases: Enum

    What a motor is doing.

    Attributes:

    Name Type Description
    STOPPED

    Braked: both outputs low. Stops quickly and resists turning.
    COASTING

    Outputs open. Spins down freely.
    RUNNING

    Driven.
    FAULT

    A latched fault. Call clear_fault().

    ControlMode ¶

    Bases: Enum

    Control mode, set by the PMODE jumper JP1 on the board.

    Attributes:

    Name Type Description
    PH_EN

    Default (JP1 open): EN = speed PWM, PH = direction.
    PWM

    JP1 bridged: IN1 / IN2. Allows per-motor coast.

    Motor ¶

    Motor(name: str, board: 'MotorBoard', en_pin: int, ph_pin: int, *, mode: ControlMode, backend, sensor: Optional[MotorCurrentSensor] = None, invert: bool = False, pwm_frequency: float = 1000.0, min_speed_pc: float = 0.0, ramp_time: float = 0.0, reverse_delay: float = 0.1, stall_current: Optional[float] = None, stall_time: float = 0.5, start_grace: float = 0.3, open_load_current: float = 0.03, open_load_time: float = 1.0, continuous_current: float = 1.5, overload_time: float = 5.0, policy: Optional[FaultPolicy] = None, motor_voltage: Optional[float] = None)

    One brushed DC motor.

    Create motors through MotorBoard, not directly. Pass options to both motors with motor_options=, or to one with a_options= / b_options=.

    Speeds are percentages, 0–100. run() takes a signed speed: positive is forward, negative is reverse. Commands are thread-safe.

    Example 
    m = board.motor_a
m.forward(60, duration=2, wait=True)   # 60 % for 2 s, then brake
m.reverse(40)
m.speed_pc = 80                        # change speed while running
print(m.current)                       # amps, if a sensor is fitted
m.coast()

    Parameters:

    Name Type Description Default
    name str

    Motor name within its board, for example "a" or "left".

    		 required
    board 'MotorBoard'

    The owning MotorBoard.

    		 required
    en_pin int

    GPIO for EN (PH/EN mode) or IN1 (PWM mode).

    		 required
    ph_pin int

    GPIO for PH (PH/EN mode) or IN2 (PWM mode).

    		 required
    mode ControlMode

    The board's ControlMode.

    		 required
    backend

    The Backend that creates the pins.

    		 required
    sensor Optional[MotorCurrentSensor]

    Optional MotorCurrentSensor.

    		 None
    invert bool

    Swap forward and reverse (instead of swapping the motor wires).

    		 False
    pwm_frequency float

    PWM frequency (Hz).

    		 1000.0
    min_speed_pc float

    Non-zero speeds below this are raised to it, to overcome the motor's deadband. 0 disables.

    		 0.0
    ramp_time float

    Seconds to ramp from 0 to 100 %. Speed changes ramp proportionally. 0 = instant.

    		 0.0
    reverse_delay float

    Seconds of braking before a direction change while running.

    		 0.1
    stall_current Optional[float]

    Motor current (A) treated as a stall. Default: 80 % of the board's current limit.

    		 None
    stall_time float

    Seconds the stall condition must last.

    		 0.5
    start_grace float

    Seconds after a start or speed change during which stall and open-load checks are skipped (start-up surge).

    		 0.3
    open_load_current float

    Current (A) below which a driven motor counts as disconnected.

    		 0.03
    open_load_time float

    Seconds the open-load condition must last.

    		 1.0
    continuous_current float

    Current (A) the motor may carry continuously.

    		 1.5
    overload_time float

    Seconds above continuous_current before an overload fault.

    		 5.0
    policy Optional[FaultPolicy]

    FaultPolicy for this motor.

    		 None
    motor_voltage Optional[float]

    The motor's rated voltage (V), or None. When it is below the board's supply_voltage, 100 % speed is scaled to a PWM duty of motor_voltage / supply_voltage, so the motor never receives more than its rated average voltage. Requires supply_voltage on the board.

    		 None

    Raises:

    Type Description
    ConfigError

    An option is out of range.

    speed_pc property writable ¶

    speed_pc: float

    Commanded speed, 0–100 %.

    Setting it while the motor runs changes the speed (ramped if ramp_time is set). Setting 0 stops the motor. Setting it while stopped stores the speed for start().

    Raises:

    Type Description

    current property ¶

    current: Optional[float]

    Motor current (A), read from the sensor now, or None without a sensor.

    While running, the reading is corrected for PWM duty. See read_current().

    stop ¶

    stop() -> None

    Brake: both outputs low. The motor stops quickly.

    Cancels any timed run or ramp. brake() is an alias.

    coast ¶

    coast() -> bool

    Let the motor spin down freely (outputs open).

    In PWM mode this is per motor. In PH/EN mode the DRV8874 can only coast by sleeping, which affects every motor on the same nSLEEP line (both motors on the board, and any board sharing the GPIO). So it coasts only if all those motors are idle. Otherwise the motor brakes.

    Returns:

    Type Description
    bool

    True if the motor is coasting, False if it had to brake instead.
