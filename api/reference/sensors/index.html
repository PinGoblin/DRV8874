    Current sensors¶

    Current sensing: the ADS1115 driver and current-sensor classes.

    Board A outputs 0.675 V per amp on A_ISENSE and B_ISENSE (J3 pins 7 and 8). One ADS1115 has four inputs, so it reads two boards (four motors). Up to four ADS1115 boards share one I²C bus (addresses 0x48 to 0x4B).

    ISENSE is zero during the PWM off-time. The ADS1115 is a delta-sigma converter that averages each reading over about 1.2 ms, so with PWM at 1 kHz or faster one reading is roughly duty × motor current. Motor.read_current() divides by the duty to estimate the motor current.

    ISENSE_V_PER_A module-attribute ¶

    ISENSE_V_PER_A = 0.675

    Board A ISENSE gain: 0.675 V per amp (1.5 kΩ × 450 µA/A, the DRV8874 IPROPI gain).

    ADS1115 ¶

    ADS1115(bus=1, address: int = 72, full_scale: float = 4.096, data_rate: int = 860)

    Minimal, thread-safe ADS1115 driver (single-shot, single-ended inputs).

    Works with a PinGoblin ADS1115 board or any ADS1115 breakout.

    Example 
    from pingoblin_motor import ADS1115, MotorBoard

adc = ADS1115(bus=1, address=0x48)
board = MotorBoard(a_en=12, a_ph=5, b_en=13, b_ph=6,
                   adc=adc, a_sense_channel=0, b_sense_channel=1)

    Parameters:

    Name Type Description Default
    bus

    I²C bus number (1 on a Raspberry Pi), or an object with write_i2c_block_data() and read_i2c_block_data() such as smbus2.SMBus.

    		 1
    address int

    0x48 (ADDR to GND), 0x49 (VDD), 0x4A (SDA) or 0x4B (SCL).

    		 72
    full_scale float

    Input range (V). 4.096 covers ISENSE at 5 V logic.

    		 4.096
    data_rate int

    Samples per second.

    		 860

    Raises:

    Type Description
    ConfigError

    Invalid address, range or rate, or smbus2 is not installed.
