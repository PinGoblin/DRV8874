    Faults¶

    Fault types, fault records, fault policies and the library's exceptions.

    A fault is detected by the FaultMonitor and delivered as a Fault record. Each motor then reacts according to its FaultPolicy: brake, coast, sleep the board, or report only. Serious faults latch, so the motor refuses to run until you call Motor.clear_fault().

    DEFAULT_ACTIONS module-attribute ¶

    DEFAULT_ACTIONS = {FaultType.STALL: FaultAction.BRAKE, FaultType.CURRENT_LIMIT: FaultAction.NONE, FaultType.DRIVER_FAULT: FaultAction.SLEEP, FaultType.OPEN_LOAD: FaultAction.BRAKE, FaultType.OVERLOAD: FaultAction.BRAKE, FaultType.BOARD_OVERLOAD: FaultAction.BRAKE, FaultType.CHAIN_OVERLOAD: FaultAction.BRAKE, FaultType.SENSOR_ERROR: FaultAction.NONE}

    Default FaultAction for each FaultType. Override per motor with a FaultPolicy.

    LATCHING module-attribute ¶

    LATCHING = {FaultType.STALL, FaultType.DRIVER_FAULT, FaultType.OPEN_LOAD, FaultType.OVERLOAD}

    Fault types that latch: the motor refuses to run until clear_fault() is called.

    FaultType ¶

    Bases: Enum

    Every fault the library can detect.

    Faults marked needs sensor are only detected when the motor has a current sensor (for example a PinGoblin ADS1115 board). The others work from the board's nFAULT line.

    Member Detected when Needs sensor
    STALL Motor current at or above stall_current for stall_time while driven, or nFAULT low (current limiting) for stall_time when there is no sensor No
    CURRENT_LIMIT nFAULT low while a motor is driven. A warning, repeated at most every 5 s No
    DRIVER_FAULT nFAULT low for 0.2 s with no motor driven: output short, overcurrent or over-temperature shutdown No
    OPEN_LOAD Under open_load_current for open_load_time while driven at 20 % duty or more: motor disconnected, broken wire, motor supply off or board fuse tripped Yes
    OVERLOAD Above continuous_current for overload_time Yes
    BOARD_OVERLOAD Board supply current above the 3 A fuse rating for 1 s Yes
    CHAIN_OVERLOAD Daisy-chain supply current above the chain limit (6 A) for 1 s Yes
    SENSOR_ERROR The current sensor could not be read (reported once until it recovers) Yes

    FaultAction ¶

    Bases: Enum

    What the library does to a motor when a fault is detected.

    Member Action
    NONE Record and report only
    BRAKE Stop the motor with the brake (EN low)
    COAST Let the motor coast if possible, otherwise brake
    SLEEP Put the whole board to sleep (all motors coast). Brakes if the board has no sleep pin

    FaultPolicy dataclass ¶

    FaultPolicy(actions: dict = dict(), latch: bool = True)

    Per-motor fault response: the action for each fault type, and whether faults latch.

    Fault types not listed in actions use the defaults in DEFAULT_ACTIONS. With latch=True, STALL, DRIVER_FAULT, OPEN_LOAD and OVERLOAD latch.

    Attributes:

    Name Type Description
    actions dict

    Maps a FaultType to a FaultAction.
    latch bool

    Whether latching fault types latch for this motor.
    Example 
    from pingoblin_motor import FaultAction, FaultPolicy, FaultType

# Coast on a stall, and don't latch (e.g. homing against an end stop)
policy = FaultPolicy({FaultType.STALL: FaultAction.COAST}, latch=False)
board = MotorBoard(a_en=12, a_ph=5, a_options=dict(policy=policy))

    Fault dataclass ¶

    Fault(type: FaultType, message: str, board: Optional[str] = None, motor: Optional[str] = None, value: Optional[float] = None, timestamp: float = monotonic())

    A record of one detected fault. Immutable.

    str(fault) gives a one-line summary such as [stall] front.a: motor stalled: 1.82 A for 0.5 s.

    Attributes:

    Name Type Description
    type FaultType

    What was detected.
    message str

    Human-readable description, including the likely cause.
    board str | None

    Board name, or None for a chain-wide fault.
    motor str | None

    Motor name, or None for a board-wide fault.
    value float | None

    The measured value that triggered it (amps), if any.
    timestamp float

    time.monotonic() when it was detected.
